# Инструкция 

Из-за траблов с регистрацией Cisco и неимением адекватных решений данной проблемы (Как минимум в моем случае) дропаю нуждающимся Packet Tracer + crack к нему.
Версия Packet Tracer 8.2.1.0118 (Конфликтов с лабами быть не должно)

[file](https://disk.yandex.ru/d/rM2_ScPB4bS2aQ)

Как поставить:
1) Устанавливаете Cisco с архива
2) Кидаете .exe с кряка (Тот же exe`шник для запуска проги, только с вырезанной регистрацией и проверкой) в корневую папку, где у Вас установлен Packet Tracer.
Оригинальный .exe`шник можете снести, более не понадобится
3) Запускаете логично через .exe или ярлык с рабочего (Должен подсосаться к кряку, вместо основного)
